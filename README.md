# 精力偷取 · Energy Theft

![精力偷取图标](assets/icon.png)

**不重复造轮子：先找现成成果，验证后复用，只补真正的缺口。**

作者：阿宽（AKuan） · 免费开源 · MIT

精力偷取是给 AI 助手使用的工作方法 Skill。遇到实际任务，它让助手先按第一性原理明确目标、事实和硬约束，查自己的已有成果、现有工具和社区方法，核验后复用，最后完成交付。

## 怎么调用

安装后，在已有任务里说一句：

> 用精力偷取

新任务在后面加上你要做的事即可。目标、材料、约束和验收由助手从上下文理解，不需要你填写模板或记版本号；只有缺失信息会影响结果或权限时才补问。

是否能按中文名称自动识别由宿主决定；支持显式技能调用的环境也可选中“精力偷取”或使用 `$energy-theft`。联网、文件访问和执行能力由当前环境提供。

## 安装

可使用 `npx skills add XNRakuan1996/energy-theft`，按提示选择支持的 AI 助手；也可按所用助手的文档安装本仓库的 [skills/energy-theft](skills/energy-theft/SKILL.md) 文件夹。保留整个目录，以便读取按需参考。

## 它具体做什么

- 先查已有成果和工具，能接续就接续；已知简单操作直接做。
- 把剩余缺口转成具体查询，找到一部分就继续补缺口，访问失败则保留真实限制。
- 核对来源、版本、许可和当前适用性，选择直接复用、最小适配或组合。
- 完成用户的实际任务并验收结果，留下必要的来源、借用部分、缺口和验证记录。

具体方法见 [SKILL.md](skills/energy-theft/SKILL.md)，查找与转向见[查找方法](skills/energy-theft/references/community-sources.md)。

## 真实边界

它是一套方法指令，不内置搜索引擎、逆向工具、付费服务或执行器，不扩大现有权限。它不会修改模型权重或自动在后台持续训练，也不保证每次都能找到现成方案或节省固定时长。反馈与修订由执行者在任务授权内完成。

当前版本为 **V0.7.0-candidate.2**，仍是候选。格式通过、调用成功和某项产物可用不等于已经证明稳定减少重复工作、返工或用户纠偏。版本变化见[公开版本记录](skills/energy-theft/CHANGELOG.md)。

欢迎反馈具体任务、环境、实际结果和失败条件；请勿在公开反馈中包含个人信息、公司内部资料、凭据或原始私人记录。
