# 精力偷取 · Energy Theft

![精力偷取图标](assets/icon.png)

**不重复造轮子：先找现成成果，验证后复用，只补真正的缺口。**

作者：阿宽（AKuan）

精力偷取是一个面向 AI 助手的工作方法 Skill：当你开发新功能、选择工具、设计工作流或排查陌生问题时，帮助助手先检查已有成果和社区经验，再判断适配、验证关键条件，最后决定复用或开发哪些缺口。

## 怎么使用

可使用 `npx skills add XNRakuan1996/energy-theft`，并按提示选择支持的 AI 助手。也可按所用助手的文档将 `skills/energy-theft` 安装到对应技能目录。

安装后，可以对支持 Agent Skills 的助手说：

> 使用精力偷取，帮我找适合本地批量处理 PDF 的现有工具；检查许可、平台要求和已知限制，再选一个用非敏感样本测试。

也可以在支持显式技能调用的环境中使用 `$energy-theft`。不同助手的安装、自动触发、联网和工具权限取决于各自环境。

## 包含什么

- 区分轻量、标准和深入三种工作深度。
- 从现有项目、GitHub、技能目录与相关社区寻找实现和失败经验。
- 区分公开材料、已有实现、他人测试与当前环境实际验证。
- 按需记录复用决策、许可条件、未知项和真实交付边界。

## 不包含什么

它是一套可复用的方法，不内置搜索引擎、付费服务或逆向工具；联网能力需要运行环境提供。它不会自动获取额外权限，也不保证每次找到现成方案、节省固定时长或替代真实任务验收。简单改字、翻译和明确的一步操作不必使用它。

## 示例

例如，用户希望批量提取 PDF 文字。助手可先查现有工具，再比较候选对扫描件、语言、平台和许可的支持，最后使用获准的非敏感样本验证；如样本未覆盖扫描件，应把 OCR 效果标为未知。这是说明流程的示例，不是本项目已完成的实测案例。
